The [GitHub releases](https://github.com/NVlabs/FastGen/releases) are the maintained release history, including tags and release notes.

Benchmark results in the method guides were obtained with [FastGen v0.1.0](https://github.com/NVlabs/FastGen/releases/tag/v0.1.0). Use that revision and the corresponding configuration when reproducing those results.

Each generated guide links to the source revision used to build it. Use that link to inspect the exact configuration and implementation associated with the documentation.
